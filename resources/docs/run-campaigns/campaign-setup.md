# Campaign setup

A campaign is a focused fundraising goal with its own page, donations, and insights.

![Campaigns list](/images/docs/app-campaigns.png)

## Creating a campaign

1. Go to **Campaigns** and click **New campaign**.
2. Enter a title, description, and fundraising goal.
3. Set a start date, end date, or keep it open-ended.
4. Publish the campaign to make it live.

## Best practices

- Use a clear, compelling title.
- Add a cover image that reflects your cause.
- Define realistic goals and explain how donations will be used.

Once published, you can share the campaign URL directly or embed a donation widget on your site.
