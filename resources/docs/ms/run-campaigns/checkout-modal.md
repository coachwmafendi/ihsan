# Modal pembayaran

Modal pembayaran membolehkan penderma menyelesaikan sumbangan tanpa meninggalkan laman web anda.

![Borang sumbangan](/images/docs/donation-form.png)

## Cara ia berfungsi

- Penderma mengklik butang sumbangan pada halaman anda.
- Modal terbuka dengan borang sumbangan yang telah dikonfigurasi.
- Penderma memilih jumlah, mengisi butiran, dan membayar.
- Modal ditutup secara automatik selepas pembayaran berjaya.

## Konfigurasi

Anda boleh menetapkan jumlah lalai, jumlah yang disarankan, dan pilihan berulang daripada tetapan elemen. Modal ini boleh diakses dan mesra papan kekunci.
