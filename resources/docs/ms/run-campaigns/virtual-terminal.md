# Terminal maya

Terminal maya membolehkan anda merekodkan sumbangan yang dikumpulkan di luar Ihsan, seperti tunai, cek, atau pemindahan bank.

![Terminal maya](/images/docs/app-virtual-terminal.png)

## Bilakah menggunakannya

- Penderma memberikan tunai kepada anda di acara.
- Penyokong menghantar pemindahan bank terus.
- Anda menerima cek melalui pos.

## Merekodkan pembayaran

Buka terminal maya, pilih kempen, masukkan butiran penderma, dan tandakan kaedah pembayaran. Sumbangan akan dipaparkan dalam laporan anda bersama sumbangan dalam talian.
