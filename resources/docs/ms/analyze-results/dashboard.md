# Dashboard

Dashboard memberikan organisasi anda gambaran keseluruhan prestasi pengumpulan dana.

![Dashboard](/images/docs/app-dashboard.png)

## Metrik utama

- Jumlah terkumpul bulan ini.
- Bilangan penderma dan pelanggan berulang.
- Derma terkini dan kemajuan kempen.
- Pembayaran dan yuran akan datang.

Anda boleh menapis dashboard mengikut julat tarikh untuk membandingkan prestasi semasa dengan tempoh sebelumnya.
