# Upgrade links

Upgrade links allow you to ask existing donors to increase their recurring contribution with one click.

![Subscription detail](/images/docs/app-subscription-detail.png)

## How to send an upgrade link

1. Open a donor or subscription record.
2. Generate a secure upgrade link.
3. Copy the link into an email, SMS, or social message.

## Donor experience

The donor opens the link, reviews the new amount, and confirms the change. No login is required because the link contains a signed token tied to that subscription.
