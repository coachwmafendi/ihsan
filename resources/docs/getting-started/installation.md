# Installation

Adding Ihsan to your website takes a single script tag and an element token.

## Quick start

1. Copy your element token from the Ihsan dashboard.
2. Paste the embed script just before the closing `</body>` tag on the page where you want donations to appear.
3. Customize the `data-type` attribute to render a floating button, inline button, popup, or embedded form.

## Example

```html
<script
    src="https://your-domain.test/e/widget.js"
    data-token="E3N4O5P6"
    data-type="floating-button"
    async
></script>
```

After the script loads, the widget will render automatically. You can manage the widget content and style from the Ihsan dashboard without editing the code again.
