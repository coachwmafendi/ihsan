# Test mode

Test mode lets you simulate donations and review the donor experience without processing real payments.

![Login page](/images/docs/login.png)

## Enabling test mode

- Toggle test mode from the organization settings page.
- Use the Stripe test keys or CHIP test credentials for your connected payment provider.
- Make a test donation with the provided test card numbers.

## What you can test

- One-time donations through embedded widgets.
- Checkout modals and campaign pages.
- Recurring subscription flows.
- Webhook deliveries and receipt emails.

Remember to switch to live credentials before launching your campaign publicly.
