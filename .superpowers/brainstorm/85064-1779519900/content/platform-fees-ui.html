🔄 3. Monthly Invoice Flow (Auto)

  Every 1st of the month:
    ┌─ php artisan ihsan:generate-monthly-invoices
    │
    ├─ 1. Kumpul semua PlatformFee status "pending" (bulan lepas)
    ├─ 2. Group by NGO
    ├─ 3. Untuk setiap NGO:
    │     ├─ Create Stripe Invoice
    │     ├─ Send invoice email ke NGO
    │     └─ Update fees → "invoiced"
    └─ 4. Log results
